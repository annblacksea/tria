# tria

## Используемые технологии

- React + JS
- Tilewind
- React Router
- Redux Toolkit
- Mock backend (JSON-server)
- React Hook Form + yup

## Реализованы функции

- Первичная реализация BFF
- Регистрация, вход и выход пользователя
- Заданы роли пользователя
- Список пользователей
- Удаление и смена роли пользователя
- Проверка доступа
